# KPOP-card · K-pop 全息拆包抽卡互动台

一款 K-pop 主题的网页撕包抽卡模拟器。横向撕开镀铝封口卡包，每包翻出 5 张全息照片小卡，收录五档稀有度典藏图鉴。纯原生 CSS 3D + SVG + Canvas + Web Audio 实现，零依赖，开箱即用。

> 镀铝封口物理撕裂 · 全息照片小卡 · 五档稀有度典藏图鉴 · 摇包验稀有度 · 三包保底

## ✨ 核心特色

- **74 张照片小卡**：卡面保留原照片背景，全息光栅在人物身后随视角变化。卡池按蓝 / 金 / 彩三档品质随机分配——蓝色对应普通与稀有（低档，44 张），金色对应全息与超稀有金卡（中档，20 张），彩色对应秘藏卡（最高档，10 张），档位高低与开包保底逻辑一致。
- **8 款 Q 版卡包**：蝴蝶结兔、浅蓝猫、灰猫、蓝花、橘猫、小狗、小老虎和小狮子会眨眼、跟随鼠标，并在摇包和撕包时切换表情。
- **5 款 K-pop 卡背**：应援棒、舞台安可、黑胶唱片、拍立得和巡演票根每包各出现一次。悬停时卡牌抬起、倾斜，图案随之放大。
- **五档稀有度与典藏图鉴**：支持摇包验稀有度、全闪模式和三包保底。收录进度保存在当前浏览器，集卡相册式网格一格一张，支持长按预览与点击全屏查看。
- **炉石式出金**：超稀有 / 秘藏翻牌时卡牌冲向舞台中央、悬停爆闪后原路归位——弧线弹射、全屏闪光、冲击波、火花爆散与金色光环，特效拉满。
- **原生 Web 实现**：CSS 3D、SVG、Canvas 和 Web Audio 实时驱动动画与音效，支持明暗舞台切换和静音，响应式适配手机、平板与电脑。

## 🚀 本地运行

需要 Node.js 18 或更新版本。克隆仓库后进入项目目录，直接启动内置静态服务，无需安装任何依赖。

```bash
git clone https://github.com/ya-chang/card-pack-simulator.git
cd KPOP-card
npm start
```

打开 [http://127.0.0.1:4180/](http://127.0.0.1:4180/)。如果端口已被占用，以终端输出的地址为准。

## 🎮 操作指南

1. **撕包**：按住卡包顶部封口，向左右任一方向横拖。也可以直接点按封口拆包。
2. **翻牌**：拆包后点击卡背，或用「一键翻开」批量翻牌。再次点击已翻开的卡牌可放大检视。
3. **卡包检视**：长按卡包进入 3D 旋转检视，拖动可全方位旋转查看。
4. **典藏册**：打开「典藏册」查看收录情况。卡片一格一张平铺展示，长按卡片预览，点击直接全屏查看。右上角可切换灯光和静音。

## 📁 项目结构

- [`src/cards-config.js`](src/cards-config.js) — 卡池、卡包、卡背和稀有度配置。
- [`src/main.js`](src/main.js) — 撕包、抽卡、翻牌、旋转检视与图鉴交互。
- [`src/styles.css`](src/styles.css) — 明暗舞台、铝箔材质、全息效果与响应式布局。
- [`src/sound.js`](src/sound.js) — Web Audio 实时合成互动音效。
- [`assets/`](assets/) — 照片卡图、人物遮罩、Q 版封面、卡背与分享横幅。
- [`server.mjs`](server.mjs) — 零依赖静态文件服务器。

## 🛠 技术栈

- **零依赖**：纯原生 HTML / CSS / JavaScript，无构建步骤、无第三方框架。
- **CSS 3D**：`transform-style: preserve-3d`、`perspective` 驱动卡包与卡牌三维空间。
- **Canvas 2D**：纸屑粒子与冲击波特效。
- **Web Audio API**：实时合成撕包、翻牌、出金等音效，无音频文件依赖。
- **响应式**：CSS Grid + 媒体查询，适配手机、平板与桌面。
